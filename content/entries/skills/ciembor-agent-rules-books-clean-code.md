# Clean Code Skill
Use this skill when a task involves everyday implementation quality, naming, small functions, readable control flow, responsibilities, comments, errors, or tests.

Before making design or code decisions, read and apply [clean-code.mini.md](https://github.com/ciembor/agent-rules-books/blob/main/clean-code/clean-code.mini.md). Use [clean-code.md](https://github.com/ciembor/agent-rules-books/blob/main/clean-code/clean-code.md) only as a deeper reference when the mini rules are not enough for the current code-quality tradeoff.
