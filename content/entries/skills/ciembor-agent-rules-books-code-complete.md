# Code Complete Skill
Use this skill when a task involves disciplined software construction: routine design, variable use, class design, control flow, defensive programming, coding standards, or implementation testing.

Use [code-complete.md](https://github.com/ciembor/agent-rules-books/blob/main/code-complete/code-complete.md) only as a deeper reference when the mini rules are not enough for the current construction tradeoff.
